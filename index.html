Design and Evaluation of a Lightweight Alert Correlation Engine for a Mini SOC

A Bachelor's Final Year Project building a fully open-source Security Operations Center with a custom Python correlation engine. The system integrates Suricata, Wazuh, and Filebeat to detect, correlate, and prioritize internal network threats. Evaluated through a three-configuration comparison (network-only, host-only, correlated) across six attack scenarios and 180 controlled experiments. Built for small organizations that cannot afford commercial SIEM solutions.

Research Question

Can a lightweight, rule-based correlation engine reduce duplicate SOC alerts while preserving detection coverage in a resource-constrained Mini SOC?

What I Built

  • Integrated Suricata + Wazuh + Filebeat + custom Python correlation engine
  • 4-VM isolated lab: Kali, Metasploitable 3, Windows 10, Ubuntu SOC-Server
  • 68,753 Suricata rules loaded, plus custom direction-agnostic detection rules
  • Wazuh agents deployed on Linux and Windows endpoints
  • MITRE ATT&CK auto-mapping enabled

How I'm Evaluating It

  • Three configurations: network-only, host-only, correlated
  • 6 attack scenarios × 10 repetitions = 180 experiments
  • Metrics: detection rate, false positives, latency, ATT&CK coverage, alert reduction, resource use
