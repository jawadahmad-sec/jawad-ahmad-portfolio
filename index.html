Final Year Project

🟢 In Progress

Open-Source Mini SOC for Automated Threat Detection

Designing and building a fully open-source Security Operations Center for small organizations that can't afford commercial SIEM tools. The system integrates Suricata (Network IDS), Wazuh (SIEM), and a custom Python correlation engine to detect, group, and prioritize internal threats with MITRE ATT&CK mapping.

Key Features

  • Real-time network intrusion detection with Suricata
  • Centralized log collection and analysis with Wazuh
  • Custom Python correlation engine with risk scoring
  • MITRE ATT&CK mapping for detected attacks
